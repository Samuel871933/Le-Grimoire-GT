Mini tutoriel

Installer un script dans Guerre Tribale

  1. 1
    Ouvre la barre de raccourcis

    Dans Guerre Tribale, ouvre « Réglages », puis sélectionne « Barre de raccourcis » dans le menu de gauche.

  2. 2
    Ajoute une nouvelle entrée

    Dans la section « Modifier », clique sur « Ajouter une nouvelle entrée » pour afficher le formulaire d’ajout.

  3. 3
    Renseigne le script

    Choisis un nom reconnaissable, puis colle l’intégralité du code javascript:… de la fiche dans le champ prévu pour le lien ou la cible.

  4. 4
    Enregistre et vérifie

    Valide la nouvelle entrée. Elle apparaît dans ta barre de raccourcis ; ouvre ensuite l’écran adapté avant de l’utiliser et vérifie toutes les valeurs.

Méthode officielle recommandée : vérifie d’abord si le script est disponible dans « Réglages → Bibliothèque de scripts ». Pour une entrée externe, utilise uniquement un script préalablement approuvé pour ton marché et ton monde pendant la période de transition.
Installation simplifiée

Un seul raccourci pour le Grimoire

Automatique
✦

Lanceur Grimoire GT

Ajoute une seule entrée dans la barre de raccourcis. Le lanceur récupère ensuite automatiquement la bibliothèque publiée sur ce site. Chaque script propose alors deux actions : Lancer pour l’exécuter uniquement pendant la session en cours, ou Remplir pour compléter automatiquement le formulaire officiel d’ajout — tu relis et tu cliques toi-même sur « Sauvegarder ».

  1. Déploie ou ouvre cette page depuis son adresse HTTPS définitive.
  2. Clique sur « Copier le lanceur ».
  3. Dans GT : Réglages → Barre de raccourcis → Ajouter une nouvelle entrée.
  4. Nom : « Grimoire GT » · Lien : colle le code copié, puis enregistre.
  5. Va dans Réglages → Barre de raccourcis → Ajouter une nouvelle entrée, ouvre le lanceur et clique « Remplir », puis Sauvegarder.
Le lien sera généré automatiquement depuis l’adresse du site.

Avant d’utiliser un script externe

Ces bookmarklets téléchargent du JavaScript depuis des sites tiers. Le contenu distant peut être modifié après publication. Lis le code source, n’exécute jamais un script qui demande ton mot de passe et vérifie les règles de ton serveur. Ce grimoire documente les liens de la capture, sans garantir leur sécurité ni leur conformité.
